# Employee Absenteeism Prediction

## Overview

This project uses Machine Learning to predict whether an employee is likely to have excessive absenteeism based on historical absenteeism records.

The workflow includes:

- Data preprocessing 
- Feature scaling using a custom scaler
- Logistic Regression model training
- Model persistence using Pickle
- Prediction on new unseen data

---

## Dataset

The dataset contains employee information such as:

- Reason for Absence
- Transportation Expense
- Distance to Work
- Age
- Daily Work Load Average
- Body Mass Index
- Education
- Children
- Pets
- Date of Absence

The target variable is generated by comparing absenteeism hours to a threshold value and converting it into a binary classification problem.

---

### Reason Categories

The original "Reason for Absence" column is transformed into four categories accordingly:

| Category | Reasons |
|-----------|-----------|
| Reason_1 | 1 - 14 |
| Reason_2 | 15 - 17 |
| Reason_3 | 18 - 21 |
| Reason_4 | 22 - 28 |

Dummy variables are created and grouped into these categories to reduce dimensionality and avoid multicollinearity.

---

### Date Features

The Date column is converted into:

- Month
- Day of Week

These features help capture seasonal and weekly absenteeism patterns.

---

### Education

Education is transformed into a binary variable:

| Original Value | New Value |
|---------------|-----------|
| 1 | 0 |
| 2 | 1 |
| 3 | 1 |
| 4 | 1 |

This separates high-school education from higher education levels.

---

## Custom Scaler

A custom scaler is implemented using Scikit-Learn's:

```python
StandardScaler
```

The scaler only standardizes selected numerical columns while preserving dummy variables.

### Scaled Features

- Month
- Day of Week
- Transportation Expense
- Distance to Work
- Age
- Daily Work Load Average
- Body Mass Index
- Children
- Pets

---

## Model

The classification model used is:

```python
LogisticRegression
```

The model predicts:

- 0 → Normal absenteeism
- 1 → Excessive absenteeism

---

1. Load dataset
